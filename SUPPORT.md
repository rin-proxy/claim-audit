# Support

Use GitHub Issues for reproducible bugs and documentation defects. Include the ClaimAudit version,
OpenClaw version, Python version, operating system, command, sanitized output and the smallest
synthetic reproduction.

Feature requests should describe the research failure or workflow gap rather than prescribing a
large implementation. Questions about private deployments, provider accounts, custom integrations
or guaranteed response times are outside community support.

Security vulnerabilities belong in a private advisory as described in `SECURITY.md`.
