# Contradiction policy

A contradiction is material when credible sources cannot both be true for the same scope and time.
Different definitions, dates, populations or versions may explain an apparent conflict; record that
explanation only after checking it.

For each conflict:

1. Link the affected claim IDs and all relevant source IDs.
2. State the exact disagreement without averaging incompatible values.
3. Check scope, definitions, dates, corrections and shared provenance.
4. Record a resolution only when evidence justifies it.
5. Set `disclosed_in_report` only after the report explains the conflict.

If unresolved, keep the claim `conflicted`, present the credible alternatives, and say what evidence
would resolve them. Do not choose the most convenient source or hide a minority result merely to
produce a single answer.
