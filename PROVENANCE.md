# Source provenance

ClaimAudit is maintained as a self-contained project. All files in this repository are distributed
under Apache-2.0 unless a file states otherwise.

`scripts/lifecycle.py` originated in Rin's private `skill-forge` project and was incorporated before
the public release. Rin owns both sources and licenses the included copy under Apache-2.0. It is now
maintained directly in ClaimAudit; cloning, building, testing, installing and contributing do not
require access to `skill-forge` or any other private repository.

The evaluation cases are synthetic. Sanitized results omit credentials, raw reasoning, user data and
private provider configuration. See the evaluation protocols for their reproducibility limits.
