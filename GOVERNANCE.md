# Governance

Rin is the initial maintainer and release owner. Maintainers review contributions, compatibility,
security reports and release evidence. Changes to claim statuses, schemas, lifecycle behavior or
accuracy claims require tests and documented migration impact.

ClaimAudit uses semantic versioning. Patch releases fix compatible defects, minor releases add
compatible capabilities, and major releases may change skill IDs, schemas or other public contracts.
Accepted contributions are Apache-2.0. Project decisions and their technical rationale should be
recorded in issues or pull requests so future contributors can inspect them.
