# Security policy

## Supported versions

The latest `2.x` release receives security fixes. Older releases may be assessed when a report shows
that the same issue is present, but no backport is guaranteed.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/rin-proxy/claim-audit/security/advisories/new).
Do not open a public issue for an undisclosed vulnerability. Include the affected version, impact,
reproduction steps and any proposed mitigation. Never include real credentials or private user data.

Maintainers will acknowledge a complete report when practical, validate its scope, coordinate a fix
and publish an advisory after affected users have a reasonable upgrade path. This project does not
offer a response-time guarantee.
